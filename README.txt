SM-GOLFO-BATABANÓ — paquete inicial reconstruido

CONTENIDO
- index.html: interfaz principal
- styles.css: estilos adaptables a teléfono
- app.js: evaluación, almacenamiento local, respaldo e informe imprimible
- sw.js: caché offline del núcleo de la aplicación
- manifest.webmanifest: instalación como PWA
- iconos PNG

IMPORTANTE
1. Publicar todos los archivos en la raíz de un repositorio GitHub Pages.
2. Abrir la URL publicada con conexión y esperar la carga completa.
3. Recargar una vez. Después, comprobar el modo avión.
4. Exportar periódicamente el respaldo JSON desde Registros.
5. No borrar los datos del navegador ni el repositorio antiguo hasta comprobar el respaldo.

LIMITACIONES DE ESTA versión inicial
- Los límites de viento/olas y calados no están precargados: deben introducirse desde la documentación oficial aplicable.
- El informe se genera en formato imprimible desde el navegador; se puede imprimir o guardar como PDF. La generación DOCX automatizada se incorporará en una siguiente fase.
- Los datos meteorológicos se introducen manualmente; esta versión no descarga pronósticos automáticamente.
- La evaluación no sustituye la decisión de la Administración ni del Capitán.
